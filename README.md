# withersky

Привет! Я **Никита** — разработчик. Делаю полезные инструменты и выкладываю их
в открытый доступ.

Пишу на JavaScript, Python и Shell. Разрабатываю браузерные расширения, системные
утилиты и плазмоиды KDE, собираю EFI-конфигурации для macOS на ThinkPad
и прошивки Padavan.

Мой главный проект — [Tabula](https://github.com/withersky/tabula-plugin):
новая вкладка браузера в виде электронной таблицы. В её же стиле оформлен
и этот профиль.
