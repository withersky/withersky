## 🛠️ Разработка

Сайт статический и собирается на Cloudflare Pages. Данные о проектах
генерируются автоматически из GitHub API — вручную их редактировать не нужно.

### Как это работает

1. Список проектов хранится в [`repos.json`](repos.json) — только slug
   репозиториев (`owner/repo`).
2. При деплое скрипт [`build.js`](build.js) запрашивает у GitHub API
   описание, язык, звёзды, homepage и дату обновления каждого репозитория
   и генерирует [`projects.json`](projects.json).
3. Фронтенд (`main.js`) загружает уже готовый `projects.json`.

`projects.json` не хранится в репозитории (см. `.gitignore`)
и пересобирается при каждом деплое.

### Добавить/убрать проект

Достаточно отредактировать `repos.json` — добавить или удалить строку
`"withersky/имя-репо"`. Остальное подтянется автоматически при следующем
деплое.

### Запуск локально

```sh
node build.js
```

### GitHub Token (рекомендуется)

Без токена GitHub API даёт 60 запросов в час — для небольшого списка этого
хватает. Чтобы не упираться в лимит, задай переменную окружения
`GITHUB_TOKEN` (Settings → Environment variables в Cloudflare Pages):
токен с доступом `public_repo` создаётся в GitHub → Settings → Developer
settings → Personal access tokens.
